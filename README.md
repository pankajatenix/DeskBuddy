# Pythonic Edutech Website

A responsive educational website for **Pythonic Edutech**, showcasing the organisation, its projects, courses, certificates, registration information, and contact details.

## Overview

The website introduces Pythonic Edutech and its focus on Python programming, web development, and data science education. It provides visitors with a central place to explore the organisation and navigate to key sections.

## Features

- **Introduction:** Landing section highlighting the organisation and its educational focus.
- **About Us:** Overview of Pythonic Edutech and its training approach.
- **Projects:** Section showcasing projects and work.
- **Certificates:** Section for certificate-related information.
- **Courses:** Area presenting courses and learning opportunities.
- **Registration:** Registration section for interested learners.
- **Contact:** Contact section and links to social profiles.
- **Responsive Design:** Stylesheets supporting the website's visual presentation across screen sizes.
- **Brand Assets:** Logos, favicons, images, stylesheets, and JavaScript resources.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Run Locally

This is a static website. No backend installation or build step is required to view its pages.

1. Clone the repository:

   ```bash
   git clone https://github.com/nameispankaj/nameispankaj.github.io.git
   ```

2. Navigate to the project directory:

   ```bash
   cd nameispankaj.github.io
   ```

3. Open `index.html` in your web browser.

For local development, you can open the folder in Visual Studio Code and use the Live Server extension.

## Deployment

This repository is named `nameispankaj.github.io` and is suitable for GitHub Pages hosting.

To configure deployment, open **Settings → Pages** in the GitHub repository and verify that the appropriate branch and folder are selected as the publishing source.

## Customisation

- Update website content in the relevant HTML files.
- Modify styles in the `css/` directory.
